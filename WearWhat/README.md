# WearWhat｜产品项目文档中心

## 项目简介

WearWhat 是一个个人独立推进的 AI 智能穿搭应用项目。项目源于发起人在日常生活中遇到的穿搭困难，以及对 AI 技术应用和产品从 0 到 1 实践的兴趣。

初步构想是支持上传衣物照片或本人照片，提供智能搭配、穿搭分析与改进建议。项目希望探索帮助用户学习穿搭、减少日常穿搭决策时间、改善现有穿搭的可能性。这些仍属于待验证的产品假设。

项目短期目标是做出个人可用的应用；未来视实际验证结果，考虑正式上线及商业化探索。

> 当前进度：00 号立项说明书已评审；01 号用户研究计划正在整理、待评审。其余文档暂为占位文件。
