# WearWhat 用户研究与需求调研报告

**文档编号：** 02  
**文档版本：** V0.1  
**文档状态：** 已评审  
**所属项目：** WearWhat  
**研究类型：** 探索性用户研究

---

## 1. 研究概况

本次研究采用在线文字访谈方式，围绕日常穿搭习惯、实际困难、现有解决方式及用户期望展开。

本次完成访谈1人，未开展在线问卷。

研究目的是了解用户真实的穿搭经历，为后续需求分析与产品定位提供初步依据。

## 2. 用户行为与使用场景

通过访谈，了解到以下穿搭习惯：

- **准备时间：** 通常提前一晚搭配衣服，因为第二天早晨时间紧张。
- **选择顺序：** 查看天气 → 选择裤子 → 搭配上衣、内搭及外套。
- **搭配标准：** 首先考虑颜色协调与整体得体，其次追求时尚感。
- **天气因素：** 下雨时会避免选择白色裤子。

## 3. 用户痛点分析

| 主要问题 | 访谈发现 |
|---|---|
| 搭配协调性不足 | 衣服颜色不协调时，容易感觉整体显老、不够时尚 |
| 穿搭决策耗时 | 反复试穿约15～20分钟，期望5分钟左右完成 |
| 穿搭参考难以复刻 | 小红书上的穿搭不一定拥有相同衣物，寻找替代款式比较麻烦 |

**典型案例：**

用户曾尝试以下搭配：

- **原搭配：** 短袖＋黑色排骨服＋白色羽绒马甲＋粉色冲锋衣＋米色裤子。
- **调整后：** 短袖＋白色排骨服＋黑白色冲锋衣＋米色裤子＋米色鞋。

用户认为原搭配颜色不协调、整体显老，通过反复试穿调整后，认为新搭配更加年轻、协调。

## 4. 现有解决方式

目前受访者主要采用以下方式解决穿搭问题：

1. **反复试穿：** 更换不同衣物，通过实际穿着效果判断是否协调，但耗费时间。
2. **参考小红书：** 浏览他人的穿搭分享，寻找搭配灵感，但不一定拥有相同衣服。
3. **放弃参考搭配：** 当缺少合适衣物时，通常直接放弃该搭配，不愿花费过多精力寻找平替。

## 5. 初步用户需求发现

根据访谈中的实际行为与反馈，提出以下待验证需求假设：

| 需求方向 | 初步需求假设 |
|---|---|
| 搭配辅助 | 用户可能需要帮助判断衣物颜色及整体搭配是否协调 |
| 决策效率 | 用户可能希望减少反复试穿，更快完成满意的穿搭 |
| 现有衣物利用 | 用户可能更倾向于获得基于已有衣物的搭配建议 |

以上属于初步需求假设，尚未验证具体产品方案能否满足这些需求。

## 6. 研究结论与局限

### 6.1 初步研究结论

本次访谈发现，受访者主要关注以下三个方面：

1. **搭配协调性：** 希望服装组合协调、得体，避免显老。
2. **搭配效率：** 希望缩短选择和反复试穿的时间。
3. **建议可执行性：** 希望穿搭参考更加容易应用，不必额外花费大量精力寻找替代衣物。

此外，受访者习惯提前一晚完成第二天的穿搭决策，说明穿搭准备时间不一定集中在早晨。

### 6.2 研究局限

- 本次仅有一份访谈资料，研究发现的适用范围有限。
- 部分信息来自用户回忆，未进行现场行为观察。
- 未开展其他用户访谈或问卷调查。
- 尚不能判断相关问题在其他用户群体中的普遍性。

### 6.3 后续研究建议

后续可进一步了解其他用户是否也存在穿搭协调性判断困难、反复试穿耗时，以及穿搭参考难以实际应用等问题。

**阶段结论：**

本次研究获得了关于穿搭协调性、决策效率和穿搭建议可执行性的初步问题线索，可以作为下一阶段需求分析的参考依据。

现有证据尚不足以证明这些问题具有普遍性，后续产品定位及功能优先级仍需进一步评估。
