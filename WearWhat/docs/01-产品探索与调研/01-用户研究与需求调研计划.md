# WearWhat 用户研究与需求调研计划

**文档编号：** 01  
**文档版本：** V0.1  
**文档状态：** 已评审  
**所属项目：** WearWhat  
**研究类型：** 探索性用户研究

---

## 1. 研究目标

本次研究旨在了解用户日常穿搭过程中存在的真实问题，为 WearWhat 后续的需求分析与产品定位提供依据。

具体研究目标如下：

1. 了解用户在日常穿搭过程中遇到的实际困难。
2. 识别穿搭困难发生的主要场景和触发条件。
3. 了解穿搭困难对用户时间、精力及穿搭体验的影响。
4. 了解用户目前采用的解决方式及其不足。
5. 探索用户对穿搭辅助的实际需求及其优先程度。

## 2. 研究对象

### 2.1 目标研究人群

本次研究优先面向**穿搭基础较弱的人群**，暂不限制年龄、性别和职业。

### 2.2 研究对象特征

重点关注具有以下特征的用户：

- 自认为缺乏一定的服装搭配知识或经验。
- 在日常选择或组合衣物时遇到过困难。
- 能够描述具体的穿搭经历及解决过程。

以上特征用于辅助筛选研究对象，不代表这类用户一定存在强烈的穿搭辅助需求。

### 2.3 研究范围说明

本次研究重点探索穿搭基础较弱用户的实际问题，不预先确定最终产品目标用户。

后续可根据研究结果及产品发展需要，针对其他用户群体开展独立研究。

## 3. 核心研究问题

| 研究维度 | 核心问题 |
|---|---|
| 穿搭困难 | 用户在日常穿搭过程中遇到哪些具体困难？ |
| 使用场景 | 这些困难通常在什么情况下发生？ |
| 问题影响 | 困难对用户的时间、精力及体验产生什么影响？ |
| 现有解决方式 | 用户目前如何解决穿搭问题？ |
| 解决效果 | 现有方式有哪些有效之处及不足？ |
| 实际需求 | 用户希望获得哪些方面的穿搭帮助？ |
| 需求优先级 | 哪些穿搭问题对用户更加重要或迫切？ |

**重点关注场景：**

每天早晨准备出门是当前重点关注的候选场景，但研究过程中不限制用户描述其他场景，以避免预设结论影响研究发现。

## 4. 研究方法与招募方案

### 4.1 研究方法

本次研究采用**一对一用户访谈与在线问卷相结合**的方式。

以用户访谈为主要研究方法，通过深入交流了解用户真实的穿搭经历、问题及现有解决方式。

在线问卷作为补充研究手段，根据访谈发现及实际研究需要开展，用于进一步了解不同用户的穿搭习惯、问题类型和使用场景。

研究规模及执行安排根据实际情况灵活调整，不预设固定访谈人数、问卷数量和执行期限。

### 4.2 用户招募

通过以下渠道招募符合条件的研究对象：

- **熟人渠道：** 朋友、同学、同事及熟人推荐。
- **线上渠道：** 小红书、微信群及其他社交平台。

根据受访者的实际情况，采用线上或线下访谈方式。

招募时尽量覆盖不同穿搭习惯和困难程度的用户，避免研究结果过度集中于单一熟人圈层。

### 4.3 用户访谈

访谈主要围绕用户过去的真实穿搭经历展开，重点了解穿搭困难出现的背景、具体问题、解决过程及最终结果。

**参考访谈提纲：**

1. 平时通常如何决定每天穿什么？
2. 能否回忆最近一次遇到穿搭困难的经历？
3. 当时是什么场景，准备去做什么？
4. 具体遇到了什么困难？
5. 最后是如何解决的？
6. 是否借助过他人的建议或其他工具？
7. 现有解决方式有哪些让你满意或不满意的地方？
8. 类似困难通常在什么情况下发生？
9. 如果可以改善穿搭过程中的一个问题，你最希望改善什么？

访谈过程中，根据用户回答进行适当追问，优先获取具体行为和实际经历。

避免通过诱导性问题影响受访者回答，不以证明WearWhat的产品构想正确为目的。

### 4.4 在线问卷

在线问卷主要用于补充用户访谈所发现的问题。

问卷内容可围绕以下方面设计：

- 日常穿搭习惯。
- 穿搭困难类型。
- 穿搭困难发生的场景。
- 穿搭困难的频率及影响。
- 当前解决穿搭问题的方式。
- 对现有解决方式的评价。
- 希望改善的穿搭问题。

具体问卷题目根据访谈结果及实际需要确定。

问卷不设置固定样本数量，其结果主要用于探索性分析，不直接代表整体市场需求。

### 4.5 研究信息保护

研究前向参与者说明研究目的及资料用途，并征得参与者同意。

如需录音，应事先取得单独同意。

研究资料尽量匿名化，不收集与研究无关的个人信息。

## 5. 研究执行计划

| 阶段 | 工作内容 | 预期成果 |
|---|---|---|
| 研究准备 | 明确研究问题、筛选条件和访谈提纲 | 研究准备材料 |
| 用户招募 | 通过熟人及线上渠道寻找研究对象 | 受访者安排 |
| 用户访谈 | 了解用户真实穿搭经历与困难 | 访谈记录 |
| 问卷补充 | 根据研究需要开展在线问卷 | 问卷结果（如开展） |
| 研究分析 | 整理用户问题、场景、影响及解决方式 | 研究发现与问题清单 |
| 研究总结 | 汇总证据、研究局限及待验证问题 | 02号研究报告 |

研究按照实际情况灵活推进，不设置固定时间安排。

## 6. 研究成果与完成标准

### 6.1 预期交付成果

本次研究预计形成以下成果：

1. 用户访谈及相关研究记录。
2. 用户穿搭问题与典型使用场景整理。
3. 用户现有解决方式及其不足分析。
4. 研究发现及相关证据。
5. 尚待验证的问题及研究局限。
6. 《02 用户研究与需求调研报告》。

### 6.2 研究完成标准

本次研究以**研究发现的有效性和信息充分程度**作为主要完成依据，不以访谈人数或问卷数量作为固定完成标准。

研究结束前重点检查：

1. 是否获得能够描述用户实际行为的真实穿搭经历。
2. 是否识别出主要穿搭困难及其发生场景。
3. 是否了解用户目前采用的解决方式及效果。
4. 是否形成有研究证据支持的初步问题判断。
5. 是否明确尚未验证的问题及研究局限。

如关键问题仍不清晰，可根据实际需要补充研究。

研究完成不代表已经证明需求普遍存在，也不代表产品方案已获得验证。

---

**阶段说明**

本次用户研究的核心目的是发现真实的用户问题，为 WearWhat 后续需求分析和产品定位提供依据。

研究过程中应保持开放性，根据实际证据形成判断。若研究发现与初始产品构想不一致，应允许调整目标用户、核心场景及产品方向。
